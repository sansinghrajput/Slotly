SLOTLY - upload guide

1. Open https://app.netlify.com/drop in your browser (Chrome is fine).
2. Drag this ZIP file (or the unzipped folder) onto the page.
3. Wait a few seconds. You get a link ending in netlify.app.
4. Sign up free with Google when it asks, so the site is kept.
   Make sure the site is set to Public so friends can open the link.
5. Open the link on your Android phone in Chrome, tap the three dots,
   then "Install app" (or "Add to Home screen"). Slotly appears on your home screen.

To update later: change index.html, change CACHE in sw.js (for example slotly-v2), and drop the files again.
